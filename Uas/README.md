### 🛠️ Tech Stack

- **Frontend:** React 18, Vite, React Router DOM v6, Tailwind CSS, Lucide Icons, Context API
- **Backend (API):** ASP.NET Core Web API / RESTful API Architecture
- **Deployment:** Vercel (Frontend) & Cloud Backend
